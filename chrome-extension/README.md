# Link Cepte — Chrome eklentisi

Araç çubuğundaki simgeye tıklayınca açık sekmenin linki Mac'teki **Link Cepte** uygulamasına kaydedilir.

## Kurulum
1. Link Cepte Mac uygulamasını **Uygulamalar** klasörüne taşıyıp bir kez açın ve klasörünüzü seçin (`linkcepte://` adresini sisteme tanıtır).
2. Chrome'da `chrome://extensions` → sağ üstten **Geliştirici modu**'nu açın.
3. **Paketlenmemiş öğe yükle** → bu `chrome-extension` klasörünü seçin.
4. Eklenti simgesini araç çubuğuna sabitleyin (yapboz simgesi → iğne).

## İlk kullanım
Chrome ilk seferde "Link Cepte'yi açmak istiyor musunuz?" diye sorar. **"chrome-extension://… her zaman bu türdeki bağlantıları ilişkili uygulamada açabilir"** kutusunu işaretleyip **Aç**'a basın; sonraki tıklamalar sormaz.

## Notlar
- Sadece `http/https` sayfaları gönderilir.
- Uygulamanın kapalıysa linkle birlikte açılır; klasör seçilmemişse önce klasörü seçmeniz istenir.
